# Smart Parking System Using IoT and Machine Learning

## Project Overview
This project aims to develop a Smart Parking System using IoT technologies and Machine Learning.

The system uses an ESP32 microcontroller and two IR sensors to detect vehicle entry and exit. It monitors parking occupancy for a parking area with a capacity of four vehicles.

A servo motor controls the parking barrier, and an I2C LCD displays the number of available parking spaces.

Machine Learning models will be trained using collected sensor data to classify the parking status as Available or Full.

## Project Objectives
- Detect vehicle entry and exit.
- Monitor parking occupancy.
- Display available parking spaces.
- Control the parking barrier automatically.
- Collect and analyze sensor data.
- Train and evaluate Machine Learning models.
